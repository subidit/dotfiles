# Tools

What each dependency is for and which parts of the configuration assume it.
Install everything with `brew bundle install --file=Brewfile`.

## Shell

| Tool | Role | Notes |
|---|---|---|
| `powerlevel10k` | Prompt | Configured by `config/zsh/.p10k.zsh`, generated by `p10k configure`. Instant prompt requires nothing to print before its block. |
| `zsh-autosuggestions` | Inline suggestion from history | Highlight colour is set from the palette (`quiet`, `Lc 34`); the default `fg=8` sits near `Lc 17`. Strategy: `history` then `completion`. |
| `zsh-syntax-highlighting` | Command-line colouring | **Must be sourced last.** Styles bound to the palette rather than the ANSI 16. |

## Replacements

| Tool | Replaces | Why |
|---|---|---|
| `eza` | `ls` | Icons, git status, and the `EZA_COLORS` vocabulary the palette targets |
| `bat` | `cat`, `man` pager | Syntax highlighting; aliased with `--style=plain` |
| `fd` | `find` | Faster, respects `.gitignore`; feeds fzf |
| `ripgrep` | `grep` | Fast. **Not aliased over `grep`** — see [rejected-defaults](../explanation/rejected-defaults.md#alias-greprg) |
| `zoxide` | `cd` | Frecency ranking; provides `z` and `zi` |
| `fzf` | — | `^T`, `^R`, `alt-C`, and `**<Tab>` |

## Editor

`fresh` — terminal-native, blocks until the buffer closes, so it needs no
`--wait` flag to work as `$EDITOR` for `git commit`. Configured separately at
`$XDG_CONFIG_HOME/fresh/`.

## Terminal

`ghostty` — chosen for native 24-bit colour, which the palette depends on, and
for its `#282c34` default background, which every contrast figure is measured
against.

Fonts: `font-jetbrains-mono` for text, `font-symbols-only-nerd-font` for icon
glyphs. Two families rather than a patched build — see
[explanation/typography.md](../explanation/typography.md#the-typeface).

## Development

`palette-report.py` needs only Python 3 from the system; there are no
third-party imports, so no virtualenv is required.
